# 关机后的黄昏（当前版本）

入口：登录页「关机」→「关闭电脑」→ 屏幕熄灭 → 下楼中...... → 宿舍楼下。「完全退出游戏」退出 Player。当前简化过场不播放独白，也不进入公寓或电梯镜头。

## 场景与操作

- 现代宿舍正对镜头，中央入口与楼梯；强化夕阳金色边光、树影和紫蓝走廊阴影。
- 恢复轻微镜头跟随：0.8 单位死区、0.55 秒缓动、偏移上限 0.65；独立近景以不同速度移动。采用 1920×1080 渲染与预缩采样像素贴图，避免低分辨率背景整像素跳动。
- 进入场景淡入 3 秒。门在入场等待后用 0.65 秒打开，再播放 1.5 秒正面下楼动画，离门后自动关闭，下楼完成后开放移动。
- A/D 或方向键移动；靠近中央楼梯（水平距离不超过 0.9 单位）显示「[ E ] 上楼 · 返回电脑」。只有靠近且按 E 才能上楼。
- 上楼播放 1.5 秒背面动画，期间锁定移动与重复触发。接近门口时开门，人物进入后用 0.65 秒关门，然后淡出 2.5 秒，保持黑屏 0.5 秒，释放场景并重播原有开机流程。Esc 不再绕过楼梯离场。
- 移动范围 ±10.5，速度 2.5 单位/秒；双向同时按下时停止，失焦不读取移动按键。

美术使用内置 imagegen，沿用现有 Turi 参考。生成要求：正面平行立面、水平阳台、中央宽楼梯、晴朗黄昏、强烈金紫对比和现代设施；楼梯精灵为 4×2 透明网格，第一行正面下楼、第二行背面上楼，统一比例和脚底基线。
