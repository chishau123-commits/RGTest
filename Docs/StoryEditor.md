# Story Editor

剧情编辑器是独立的 Unity Editor 开发工具，不进入游戏运行时构建。它负责把剧情结构、对白、角色表情差分、背景和关卡跳转导出成稳定的 JSON 数据；游戏侧以后只需要读取 JSON，不依赖 `GeometryRhythm.StoryEditor` 程序集。

## 启动

- 打开编辑器：`节奏黑客 → 剧情编辑器 → 打开剧情编辑器`
- 快捷入口：`Window → 剧情编辑器` 或 `Ctrl+Shift+G`
- 新建项目：`节奏黑客 → 剧情编辑器 → 新建剧情项目`
- 生成示例项目文件：`节奏黑客 → 剧情编辑器 → 生成初始剧情文件`
- 查看剧情数据目录：`节奏黑客 → 剧情编辑器 → 打开剧情数据目录`

默认项目路径为 `Assets/RhythmDemo/Resources/Story/main-story.json`。编辑器的临时状态只保留在 Editor 中，保存后的 JSON 才是剧情模块的输入数据。

## 当前工作流

### 1. 建立线性剧情

左侧是唯一的剧情顺序，游戏从上到下依次执行，不需要连线，也没有分支终点。每个步骤只支持：

- `对白`：说话角色、表情、默认文本和可选的文本差异。
- `选项`：显示若干按钮，每个按钮只设置一个变量值。
- `背景`：切换背景图片。
- `进入关卡`：指定关卡和谱面，结束后继续执行下一步。
- `结束`：结束章节，通常放在列表最后。

步骤可以上移、下移、复制和删除。选择只会改变变量，不会跳转步骤，因此剧情流程始终是线性的。

例如选项设置为：

```text
行动方式 = 果断
行动方式 = 谨慎
```

后续对白可以添加两条文本差异。运行时如果变量匹配，就替换默认对白；不匹配时播放默认文本。

### 2. 实时预览

中央区域切换到 `实时预览` 后，会直接读取当前编辑数据，不需要保存：

- 显示当前背景、角色表情、说话人、对白框和选项按钮。
- 点击选项会立即设置变量，并继续播放下一步。
- 后续对白会实时匹配`文本差异`，修改文本后界面下一帧更新。
- 支持`从当前步骤预览`、`下一步`、`自动播放`和`清空变量`。
- `进入关卡`步骤使用模拟通关按钮继续，不会真的启动节奏关卡。

### 3. 导入表情差分

进入右侧 `角色` 页：

1. 新建或选择一个角色。
2. 为角色增加表情槽，例如 `neutral`、`smile`、`worried`。
3. 在某个槽中点击 `导入图片`，或直接拖入项目内贴图。
4. 点击 `导入文件夹` 可一次导入整个目录；每个文件名会成为一个表情 ID，并自动去重。

导入的图片会复制到项目的剧情资源根目录，默认结构如下：

```text
Assets/RhythmDemo/StoryData/Assets/
  Characters/<character-id>/<expression-id>.png
  Backgrounds/<background-id>.png
```

导入器会自动把贴图设置为 `Sprite`、关闭 Mipmap、开启透明通道并使用 Clamp。项目只保存 `assetPath`，不在剧情 JSON 中保存 Unity 对象引用。

### 4. 校验与保存

`校验剧情与资源` 会检查：

- 步骤、角色、表情、背景和选项 ID 是否重复或缺失。
- 对白是否引用了存在的角色和表情。
- 选项是否完整设置了变量名和值。
- 进入关卡是否配置了关卡 ID 和谱面 JSON。
- 结束步骤后面是否还有其他内容。
- 表情、背景和谱面资源路径是否存在。
- 选项设置的变量是否影响后续文本。

错误会阻止误以为剧情已经可接入；警告用于允许先搭结构、后补资源。

## JSON 边界

当前格式版本为 `version: 2`。顶层包含：

```json
{
  "version": 2,
  "storyId": "main-story",
  "title": "Main Story",
  "assetRoot": "Assets/RhythmDemo/StoryData/Assets",
  "characters": [],
  "backgrounds": [],
  "nodes": [
    {
      "id": "intro-choice",
      "kind": 1,
      "title": "玩家选择",
      "text": "接下来要怎么做？",
      "choices": [
        {
          "text": "继续追踪信号",
          "variable": "行动方式",
          "value": "果断"
        }
      ]
    },
    {
      "id": "reaction",
      "kind": 0,
      "title": "选择后的对白",
      "text": "默认对白",
      "textVariants": [
        {
          "variable": "行动方式",
          "value": "果断",
          "text": "替换后的对白"
        }
      ]
    }
  ]
}
```

编辑器代码位于 `Assets/RhythmDemo/StoryEditor/Editor/`，属于 Editor-only assembly。游戏运行时可以复用同样的字段名自行解析 JSON，但不需要、也不应该引用这组编辑器类。

## 后续接入点

游戏侧剧情播放器接入时，建议把 JSON 转成 Runtime DTO，并按节点类型执行：

- `Dialogue` 更新说话人、表情，并根据当前变量选择默认文本或某个 `textVariants`。
- `Choice` 显示选项，点击后把 `variable` 设置为对应的 `value`，然后继续下一个步骤。
- `Background` 播放背景切换后继续。
- `Stage` 通过关卡 ID 和谱面路径进入现有节奏关卡流程，通关后继续下一步。
- `End` 结束章节并回写剧情进度。
